# Listening for "Exit Lucra"

Requires the client to be initialized first — see [Initialization](1.2_initialize_client.md).

Register a listener for when a user attempts to exit the Lucra experience:

```typescript
import { LucraClient } from 'lucra-web-sdk';

const client = LucraClient.getInstance();

client.on('exitLucra', () => {
  console.log('User attempted to exit Lucra!');
});
```

You can register it at any point, including before `open()`. The SDK re-enables the in-app exit control each time the Lucra iframe initializes.

To stop listening:

```typescript
const handleExit = () => { /* ... */ };

client.on('exitLucra', handleExit);
// later...
client.off('exitLucra', handleExit);
```

> When a route is shown with [`dialog()`](1.3_lucraflows.md#dialogs), the in-app close is handled by the dialog itself (it closes the dialog), so this `exitLucra` listener does not fire for it.
