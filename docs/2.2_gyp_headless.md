# Games You Play Headless

Headless functions for Games You Play (recreational game) matchups; reads work before login. For the shared mechanics every call relies on (the invisible iframe, lifecycle gating, timeouts, and the full error table) see [Headless on Web](2.0_headless.md).

## Reading a matchup

`api.matchup(matchupId)` resolves with one recreational game matchup. It needs no login: it awaits iframe initialization internally (no `await client.ready` needed), so you can render a shared matchup before the user logs in. Calls run concurrently, each with its own [15-second timeout](2.0_headless.md#request-timeout).

```typescript
const matchup = await client.api.matchup(matchupId);
const stake =
  matchup.atStake.type === 'CASH'
    ? `$${matchup.atStake.amount}`
    : matchup.atStake.reward.title;
```

An unknown id, or the id of a matchup that is not a recreational game, rejects with a `LucraApiError` with code `API_ERROR` and message `"Recreational game matchup not found"`. Unlike other `API_ERROR` failures, retrying does not help.

Matchup payloads include other users' ids (`creatorId`, `participantGroups[].userIds`). Do not log them or send them to analytics.

### `LucraMatchup`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | The matchup id |
| `status` | `LucraMatchupStatus` | See below |
| `playStyle` | `LucraPlayStyle` | `"GROUP_VS_GROUP"` (teams) or `"FREE_FOR_ALL"` |
| `isPublic` | `boolean` | |
| `createdAt` | `string` (optional) | ISO timestamp |
| `creatorId` | `string` | User id of the creator |
| `winningGroupId` | `string` (optional) | Id of the winning participant group, once there is one |
| `game` | `LucraRecreationalGame` | The game being played |
| `atStake` | `LucraAtStake` | What the matchup is played for |
| `participantGroups` | `LucraMatchupParticipantGroup[]` | The matchup's groups (teams), ordered by creation |

`LucraMatchupStatus` is one of `OPEN`, `CONFIRMED`, `LOCKED`, `PENDING_OUTCOMES`, `ON_HOLD`, `DISPUTE`, `CLOSED`, `CLOSED_TIE`, `CANCELED_BY_OWNER`, `CANCELED_DISPUTE`, `CANCELED_GAME_CANCELED`, `CANCELED_NOT_ACCEPTED`, `CANCELED_PLAYER_INACTIVE`, `CANCELED_THROUGH_API`, or `CANCELED_TIMEOUT`. The `CLOSED*` values mean the matchup finished; the `CANCELED_*` values mean it was canceled.

### `LucraAtStake`

A union discriminated by `type`:

| `type` | Field | Notes |
| --- | --- | --- |
| `"CASH"` | `amount: number` | Cash buy-in per participant |
| `"TENANT_REWARD"` | `reward: LucraReward` | Your reward the matchup is played for: `{ rewardId, title, descriptor, iconUrl, bannerIconUrl, disclaimer, metadata }`. See [Rewards](1.9_rewards.md) |

### `LucraRecreationalGame`

| Field | Type | Notes |
| --- | --- | --- |
| `gameId` | `string` | Game type id, e.g. `"AIR-HOCKEY"` |
| `name` | `string` | Display name |
| `iconUrl` | `string` (optional) | |
| `minigameEnabled` | `boolean` | Whether the game type can be played as a Lucra minigame |

### `LucraMatchupParticipantGroup`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | Group (team) id |
| `userIds` | `string[]` | User ids of the group's participants; empty when nobody has joined it |

## Matchup details

`api.matchupDetails(matchupId)` resolves with the matchup plus who is in each group, each group's standing and score, and per-player scores. Like `api.matchup`, it needs no login, awaits iframe initialization internally, runs concurrently, and rejects an unknown or non-recreational id with `API_ERROR` and `"Recreational game matchup not found"`.

```typescript
const { matchup, groups, participantScores } = await client.api.matchupDetails(matchupId);
const winner = groups.find((g) => g.id === matchup.winningGroupId);
```

The participant fields (`userId`, `username`, `avatarUrl`) are other users' data. Do not log them or send them to analytics.

### `LucraMatchupDetails`

| Field | Type | Notes |
| --- | --- | --- |
| `matchup` | `LucraMatchup` | The same object `api.matchup` returns |
| `groups` | `LucraMatchupGroup[]` | Every group, including empty ones, in the same order as `matchup.participantGroups` |
| `participantScores` | `LucraMatchupParticipantScore[]` | Per-player scores ordered by `place`; may be empty |

### `LucraMatchupGroup`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | Group (team) id, matching `matchup.participantGroups[].id` |
| `outcome` | `"WIN" \| "LOSS" \| "TIE"` (optional) | The group's current standing: `WIN` is currently winning or has won, `LOSS` is currently losing. It is not only the final result; use `matchup.winningGroupId` for the final winner |
| `score` | `number` (optional) | The group score with any override applied |
| `participants` | `LucraMatchupParticipant[]` | Empty when nobody has joined the group |

### `LucraMatchupParticipant`

| Field | Type | Notes |
| --- | --- | --- |
| `userId` | `string` | |
| `username` | `string` | |
| `avatarUrl` | `string` (optional) | |
| `individualPayout` | `number` (optional) | What this user receives if their group wins, after the fee and team split. Absent for tenant rewards |

### `LucraMatchupParticipantScore`

| Field | Type | Notes |
| --- | --- | --- |
| `userId` | `string` (optional) | |
| `username` | `string` (optional) | |
| `avatarUrl` | `string` (optional) | |
| `place` | `number` (optional) | Rank, 1 is first |
| `score` | `number` (optional) | |
| `finishedAt` | `string` (optional) | ISO timestamp |
| `groupId` | `string` (optional) | The participant's group |

## Fee

`api.gamesMatchupFee()` resolves with the games (minigame) matchup service fee as a fraction: `0.05` is 5%. It is the same value the mobile SDKs expose as `observeGamesMatchupFee`, and `0` when the tenant has no fee configured. It is not the fee on recreational (Games You Play) cash matchups: the backend applies that per wager, and `LucraMatchupParticipant.individualPayout` in [matchup details](#matchup-details) already reflects it.

Like `api.matchup`, it needs no login, awaits iframe initialization internally, and runs concurrently. It rejects with a `LucraApiError` with code `API_ERROR` when Lucra cannot read the configuration.

```typescript
const fee = await client.api.gamesMatchupFee();
const percent = fee * 100; // 5
```
