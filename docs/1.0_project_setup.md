# Getting Started

### Installing the SDK

```
bun install Lucra-Sports/lucra-web-sdk
```

`bun` is shown but installing from Github should be supported by any node package manager you're using

### Bundlers

The published JavaScript is ES modules compiled to ES2019, and the package declares `main`, `module`, and `exports`. It resolves and parses as installed on current bundlers (webpack 5, Vite, Rollup, esbuild) and on older ones that predate the `exports` field, including webpack 4 and vue-cli 4.

No bundler configuration is required. In particular, webpack 4 and vue-cli 4 need no `resolve.alias` for the package and no `transpileDependencies` entry for it, because nothing newer than ES2019 reaches their parser. If your project carries either workaround from an earlier SDK version, you can remove it.

One exception: the `lucra-web-sdk/types` subpath is declared only in `exports`, so bundlers that do not read `exports` cannot resolve it. Import from the package root instead, which re-exports every documented type.

### Typescript

The SDK was developed with Typescript in mind. If you are using Typescript, everything should be typed including the class constructor and the available methods and arguments on the LucraClient class.
